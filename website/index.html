A few useful answers.

Which versions of Windows are supported?

64-bit Windows 10 and Windows 11. The installer includes the WebView2 bootstrapper.

Can Inkfin edit my files?

No. Inkfin is deliberately read-only and never writes back to your Markdown document.

Does it work without internet?

Yes. Rendering, highlighting, search and refresh all run locally. Remote images are intentionally blocked.

Is Inkfin available for macOS?

A universal test build exists for macOS 14.2 or later on Apple silicon and Intel. It is unsigned and not notarised, and Gatekeeper rejects it. Automated CI checks confirm architecture and launch, but human interface acceptance and signed distribution checks remain outstanding, so no macOS download is offered.

Why does SmartScreen warn me?

The current installer is not code-signed. Choose “More info” and “Run anyway” if you trust the download.
