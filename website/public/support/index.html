Inkfin support

Inkfin opens local .md and .markdown documents for reading. It does not edit files.

Report a problem

Open a GitHub issue or check existing issues. The publisher is Priyanshu Maurya.

Include your Windows version, Inkfin version, installation source (Microsoft Store or standalone), steps to reproduce and what you expected. If useful, attach a small example containing only information you are comfortable making public. GitHub issues are public; do not post private documents, credentials or sensitive file paths.

Opening files

Choose Open or press Ctrl+O. You can also drop a Markdown file onto the window. To choose Inkfin as your file handler, right-click the document in File Explorer, choose Open with, and select Inkfin. Windows controls the default-app choice.

Common limits

Documents must be valid UTF-8 and no larger than 10 MiB. Remote images and raw HTML execution are blocked. Inkfin supports one open document at a time. Search, zoom, themes and live refresh run locally.

Updates and installation

For a Store installation, use Microsoft Store's update controls when a Store release is available. For the standalone version, download a release from the official GitHub releases page. The standalone installer is currently unsigned. Inkfin requires Microsoft Edge WebView2; an installation or runtime problem can prevent the window from opening.

Privacy questions

Read the privacy policy or open an issue with a general question. No account or subscription is required to use Inkfin.
